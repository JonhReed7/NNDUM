# DevPulse — вход и регистрация

Две адаптивные страницы на React по визуальному макету Figma:
https://www.figma.com/design/f2CldQ6BjtmOF1IhqdNlw8/

## Запуск

Требуется Node.js 22.12+.

```sh
npm install
npm run dev
```

Вход: `http://127.0.0.1:5173/#/login`

Регистрация: `http://127.0.0.1:5173/#/register`

```sh
npm run build
npm run preview
```

## Что входит

- Компоненты `LoginPage`, `RegisterPage`, `AuthLayout`, `AuthField`, `PromoPanel`.
- Общий CSS с мобильным вариантом; на узком экране декоративная панель сворачивается в шапку.
- Переходы между входом и регистрацией, показ пароля, чекбоксы, стандартная проверка обязательных полей и email.
- Проверка совпадения паролей и состояние ошибки, показанное в исходном макете.
- Локальные шрифты Inter через npm-пакет; нет внешних запросов за шрифтами.

Это только интерфейс. Запросов к серверу, OAuth GitHub, восстановления пароля и создания аккаунтов нет; пароли не сохраняются. Для подключения предусмотрены props `onSubmit`, `onGithub`, `onPasswordReset`, `onTerms`. `onSubmit` получает `FormData`.

`App.jsx` включает у регистрации `previewError`, чтобы воспроизвести пустое поле с ошибкой из Figma. Для обычного начального состояния уберите этот prop. При вводе полей ошибка начинает зависеть от совпадения паролей.

Точные свойства слоёв и экспорт ассетов через Figma-плагин были недоступны. Вёрстка выполнена по увеличенному визуальному просмотру; логотип, график и декор собраны средствами CSS/SVG, иконки взяты из Lucide. Мобильная компоновка адаптирована, поскольку мобильного макета в выбранных экранах нет.

## Проверка

Сборка `npm run build` проходит. В браузере проверены обе страницы, переходы, показ пароля, чекбокс, неверный email, появление и снятие ошибки несовпадения паролей. На ширинах 320 и 390 CSS-пикселей горизонтального переполнения нет. В консоли браузера ошибок и предупреждений нет.
