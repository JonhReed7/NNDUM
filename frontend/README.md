# DevPulse — интерфейс аналитики разработки

React 19, JavaScript, Vite 7 и обычный CSS. Шрифт Inter подключён локально через `@fontsource/inter`, служебные иконки — через Lucide. Новые экраны используют локальные SVG из [макета Figma](https://www.figma.com/design/f2CldQ6BjtmOF1IhqdNlw8/).

## Запуск

Требуется Node.js 22.12+.

```sh
npm install
npm run dev
```

Приложение доступно на `http://127.0.0.1:5173`. На странице входа есть кнопка «Посмотреть демо без входа».

| Страница | Адрес |
| --- | --- |
| Вход | `/#/login` |
| Регистрация | `/#/register` |
| Главная | `/#/home` |
| Новый анализ | `/#/analysis` |
| Дашборд команды | `/#/dashboard` |
| Отчёт за спринт | `/#/report` |
| Методика расчёта | `/#/methodology` |

Hash-маршруты работают и при статическом размещении. Для разработки поддерживаются также прямые пути, например `/analysis`.

Вход и регистрация используют [API DevPulse](https://nndum.onrender.com/docs). Для другого сервера скопируйте `.env.example` в `.env.local` и поменяйте `VITE_API_BASE_URL`.

После входа или регистрации сайт открывает главную и сохраняет токен и данные профиля в текущей вкладке. При выборе «Запомнить меня» вход восстанавливается после повторного открытия сайта до истечения срока действия токена. Пароль используется только для отправки формы.

Кнопки Google и GitHub получают ссылку из `GET /auth/{provider}/url` и после возврата отправляют код в `POST /auth/{provider}/callback`. Для запуска на указанном выше локальном адресе настройте в бэкенде и у провайдеров точные адреса возврата `http://127.0.0.1:5173/auth/google` и `http://127.0.0.1:5173/auth/github`.

При публикации фронтенда используйте его адрес и настройте выдачу `index.html` для страниц возврата `/auth/google` и `/auth/github`. При публикации в подпапке добавьте её и в адреса возврата, и в параметр Vite `--base`, например `npm run build -- --base /NNDUM/`.

```sh
npm run build
npm run preview
```

## Структура

- `pages/` — семь отдельных страниц, включая существующие вход и регистрацию.
- `components/WorkspaceLayout.jsx` — шапка, меню, мобильная навигация, профиль и справка.
- `components/WorkspaceUI.jsx` — общие панели, заголовки, кнопки и модальное окно.
- `Workspace.css` — стили рабочего пространства, адаптивная компоновка и печать отчёта.
- `data/demo.js` — общие данные для дашборда, отчёта, методики и экспорта.
- `services/report.js` — выгрузка CSV с UTF-8 BOM, экранированием значений и защитой от формул в ячейках.
- `assets/figma/` — оригинальные SVG из Figma; временные URL не используются в приложении.

## Поведение демо

На главной работают поиск и фильтр проектов по команде, переключение карточек команд и создание команды в памяти. Форма подключения репозитория переносит URL и команду на страницу нового анализа.

В форме анализа доступны команда, URL, ветка, необязательный хэш и даты. Проверяются обязательные поля, HTTP(S)-адрес, формат хэша и порядок дат. После запуска открывается демонстрационный дашборд, выбранные параметры используются в отчёте и выгрузке. Метрики остаются примером из Figma: запросов к GitHub и серверного расчёта пока нет.

Кнопка «Скачать CSV» выгружает восемь метрик и параметры отчёта. «Скачать PDF» открывает стандартное окно печати браузера: выберите «Сохранить как PDF». Для печати подготовлен полный отчёт вместо дашборда.

Созданные команды, изменения имени в настройках профиля и параметры анализа хранятся в памяти и сбрасываются после перезагрузки.

На узких экранах меню открывается кнопкой в шапке, карточки перестраиваются в колонку, широкие таблицы прокручиваются внутри панелей. Мобильная компоновка адаптирована самостоятельно, поскольку отдельных мобильных макетов нет.

Рабочая область занимает высоту окна: центральное содержимое прокручивается отдельно, шапка и боковое меню остаются на месте. Блок «Нужна помощь?» расположен сразу под пунктами меню. При переходе на другую страницу содержимое открывается сверху; ссылки на разделы главной прокручивают центральную область к нужному разделу. На низких экранах меню имеет собственную прокрутку. Вход, регистрация и печатный отчёт сохраняют обычную прокрутку документа.

## Проверка

`npm run build` — production-сборка. В браузере проверены навигация, поиск и пустое состояние, создание команды, фильтр проектов, валидация периода, передача ветки в отчёт, скачивание CSV, мобильное меню и независимая прокрутка содержимого. Десктопная вёрстка сверена с Figma.
