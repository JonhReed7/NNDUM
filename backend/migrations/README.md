# Database migrations

Apply migrations to an empty database:

```powershell
python -m alembic upgrade head
```

If the database already has the schema created by the previous `Base.metadata.create_all()` startup hook,
mark it as being at the initial revision without changing tables:

```powershell
python -m alembic stamp 0001_initial_schema
```

After that, use `python -m alembic upgrade head` for future schema changes.

Create a new migration with:

```powershell
python -m alembic revision --autogenerate -m "describe schema change"
```

Review autogenerated revisions before applying them.
